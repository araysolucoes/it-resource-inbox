# Stylesheet

`email_inbox.scss` is the look of the account kanban and the message cards: spacing, the off-account state, and the ready or waiting pills.

Class names start with `o_email_`. Do not rename a class unless the kanban XML that uses it changes in the same edit.

---

# Folha de estilo

`email_inbox.scss` é a aparência do kanban de contas e dos cartões de mensagem: espaço, conta desligada e as pílulas de pronto ou aguardando.

Os nomes de classe começam com `o_email_`. Não renomeie uma classe sem mudar, na mesma alteração, o XML do kanban que a usa.
