# Static files

Browser assets. `src/scss/email_inbox.scss` styles the account card and the message kanban. `views/assets.xml` adds that file to the backend bundle.

There is no JavaScript in this module. Change the stylesheet, upgrade the module, and press Ctrl+F5.

---

# Arquivos estáticos

Assets do navegador. `src/scss/email_inbox.scss` estiliza o cartão da conta e o kanban das mensagens. `views/assets.xml` inclui esse arquivo no pacote do backend.

Não há JavaScript neste módulo. Mude a folha de estilo, atualize o módulo e pressione Ctrl+F5.
