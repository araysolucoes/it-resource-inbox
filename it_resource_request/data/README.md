# Data

Records installed with the module.

- `ir_sequence.xml` numbers requests as TI/year/sequence.
- `it_resource_term_data.xml` loads the default receipt and return terms and the cron that reads third-party approval replies every five minutes.
- `it_resource_access_data.xml` loads the four menu tabs (Requests, Catalog, In use, Settings) and fills the access list from people who already had a module group.

Demo catalog rows are not in these files. They are created when someone clicks **Demo data**, so a database without that click stays empty.

# Dados

Registros instalados com o módulo.

- `ir_sequence.xml` numera os pedidos como TI/ano/sequência.
- `it_resource_term_data.xml` carrega os termos padrão de recebimento e devolução e o cron que lê respostas de aprovação de terceiros a cada cinco minutos.
- `it_resource_access_data.xml` carrega as quatro abas de menu (Requests, Catalog, In use, Settings) e preenche a lista de acessos com quem já tinha um grupo do módulo.

As linhas de catálogo de demonstração não estão nestes arquivos. Elas nascem quando alguém clica em **Demo data**, então um banco sem esse clique continua vazio.
