# Views

Screens and menus.

- `it_resource_request_views.xml` is the request kanban, list, and form. The status bar is read-only. Stage changes go through the buttons, which open the list of the next stage.
- `it_resource_need_views.xml`, `it_resource_item_views.xml`, and `it_resource_unit_views.xml` are the catalog.
- `it_resource_assignment_views.xml` is who holds an item and who already returned it.
- `it_resource_setting_views.xml` is the approval template list.
- `it_resource_access_views.xml` is the editable access list: name, login, access level, access group.
- `it_resource_term_views.xml` is the signature terms.
- `menus.xml` is IT resources: Requests, Catalog, In use, and Settings. Each folder is limited to its tab group.
- `assets.xml` loads the signature widget and the stylesheet.

**Requests** is the master list and opens grouped by stage.

# Visões

Telas e menus.

- `it_resource_request_views.xml` é o kanban, a lista e o formulário do pedido. A barra de status é somente leitura. A etapa muda pelos botões, que abrem a lista da etapa seguinte.
- `it_resource_need_views.xml`, `it_resource_item_views.xml` e `it_resource_unit_views.xml` são o catálogo.
- `it_resource_assignment_views.xml` é quem está com o item e quem já devolveu.
- `it_resource_setting_views.xml` é a lista de modelos de aprovação.
- `it_resource_access_views.xml` é a lista editável de acesso: nome, login, nível de acesso e grupo de acesso.
- `it_resource_term_views.xml` são os termos de assinatura.
- `menus.xml` é IT resources: Requests, Catalog, In use e Settings. Cada pasta fica limitada ao grupo da aba.
- `assets.xml` carrega o widget de assinatura e a folha de estilo.

**Requests** é a lista mestre e abre agrupada por etapa.
