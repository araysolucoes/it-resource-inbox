# src

Frontend sources split by kind.

- `js` is the signature field widget.
- `xml` is the QWeb used by that widget.
- `scss` is the request and signature layout.

Odoo only sees these files because `views/assets.xml` and the manifest `qweb` key list them.

# src

Fontes de frontend separadas por tipo.

- `js` é o widget do campo de assinatura.
- `xml` é o QWeb usado por esse widget.
- `scss` é o layout do pedido e da assinatura.

O Odoo só vê estes arquivos porque `views/assets.xml` e a chave `qweb` do manifesto os listam.
