# Stylesheet

`it_resource.scss` styles request cards by stage and the signature pad (`.o_it_sign_pad`): dashed border, fixed height, so the drawing area stays visible.

Class names start with `o_it_`. Change a class in the scss and in the kanban or the widget together.

---

# Folha de estilo

`it_resource.scss` estiliza os cartões do pedido por etapa e a área de assinatura (`.o_it_sign_pad`): borda tracejada e altura fixa, para a área de desenho continuar visível.

Os nomes de classe começam com `o_it_`. Mude uma classe no scss e no kanban ou no widget juntos.
